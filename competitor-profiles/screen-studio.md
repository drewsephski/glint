# Screen Studio
Checked: 2026-11-10. Scope: public product, pricing and roadmap review; no hands-on benchmark.

## Observed
[Product page](https://screen.studio/) describes polished Mac recordings with automatic zoom, cursor treatment, transcript edits and multiple aspect ratios. Listed prices: $9/month billed yearly, or $29 monthly. [Roadmap](https://screen.studio/roadmap) marks MCP as in progress, and sensitive-data masking, ProRes and transcript editing as completed.

## Interpretation
Use it as the visual-quality baseline. Basic automation and privacy features will be difficult differentiators. MCP availability must be checked before making public competitive claims; a roadmap is not proof of a working integration.

## Implication for Glint
Benchmark identical footage for cursor placement, text legibility and pacing. Prioritize reliable automated production while meeting this visual bar.

## Uncertainty
Homepage and roadmap disagree on some voiceover status. No conclusions about voiceover availability or comparative export speed.
