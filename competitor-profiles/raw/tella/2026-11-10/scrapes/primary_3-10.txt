L248: ## Frequently asked questions
L249: 
L250: What is Auto Capture?
L251: 
L252: Auto Capture is Tella's agentic screen recorder, a camera for browser agents. An AI agent opens a web page in its own browser, explores it, plans a walkthrough, and records it with an animated cursor, with no one at the keyboard. You get back a Tella recording you can edit, narrate and share like any other.
L253: 
L254: What is agentic screen recording?
L255: Agentic screen recording means an AI agent makes the recording for you. Instead of you clicking through a product while a screen recorder runs, you describe the demo you want and the agent explores the page, decides what to show, checks its script works, then films it. Tella's Auto Capture does this for web pages.
L256: 
L257: Is there a screen recorder AI agents can use?
L258: Yes. Auto Capture is built to be called by agents. Claude, ChatGPT, Claude Code, Codex, Cursor or any app connected to Tella's MCP server at https://api.tella.com/mcp can start a take with create_auto_capture, poll it with get_auto_capture, and place the finished recording in a Tella video with create_video. The Tella Agent in Tella's editor can use it too.
L259: 
L260: How can Claude make a demo video of my product?
L261: Connect Claude to Tella's MCP server, then ask it for a demo with your product's full URL and who it's for: "Use Tella to record a product demo of https://example.com for first-time visitors." Claude starts an Auto Capture take, checks on it until it's delivered, and puts it in a new Tella video, ready to trim, caption and share.
L262: 
L263: How do I start Auto Capture?
L264: Ask the Tella Agent in the editor, or an AI app such as Claude or ChatGPT connected to Tella's MCP server, for a recording of a page with its full URL. For example: "Record a 30-second tour of https://example.com/pricing for first-time visitors. End on the yearly toggle."
L265: 
L266: Can I run Auto Capture automatically, like on every pull request?
L267: Yes. Any agent connected to Tella's MCP server can start a take, including Claude Code or Codex running in a CI job or a scheduled automation, using a Tella API key as the bearer token. Point it at a URL the capture browser can reach: a preview deploy on a public domain works, localhost doesn't. If the preview needs a sign-in, save a login under Settings, then Credentials.
L268: 
L269: Can Auto Capture record pages behind a sign-in?
L270: Yes. Save a login for your product under Settings, then Credentials. The agent signs in off camera while it explores, and the recording starts already signed in. Password fields are always masked. Pick the login from 1Password and Tella fills in its one-time code too; otherwise, if your product sends a sign-in code, you enter it on a Tella page, never in the chat.
