L94: ## Frequently asked questions
L95: 
L96: What is the Tella MCP?
L97: 
L98: The Tella MCP is a secure connection that lets compatible AI agents work with your Tella videos, transcripts, clips, exports, and playlists.
L99: 
L100: What is the best MCP server for video editing?
L101: It depends on where your video starts. For screen recordings, product demos and tutorials, Tella's MCP server gives Claude, ChatGPT, Codex or Cursor more than 100 tools to edit, export and publish, and can record a web page with Auto Capture. Hosted editors like Descript suit footage you edit as text, desktop bridges drive DaVinci Resolve or Premiere Pro, and clipping servers like OpusClip turn long videos into shorts. We compare them in 【25†the best MCP servers for video editing】.
L102: Which screen recorders work with Claude and ChatGPT through MCP?
L103: 
L104: Tella does. It's in Claude's Connector Directory and ChatGPT's app directory, and any MCP client can connect to https://api.tella.com/mcp. Once connected, your agent can edit, export and publish your recordings, not just read them.
L105: 
L106: Can an AI agent record a product demo for me?
L107: Yes, with Auto Capture, which is in beta on paid plans. Ask Claude, ChatGPT or the Tella Agent for a demo of a web page. Tella's capture agent opens the URL in its own browser, plans the walkthrough and films it with an animated cursor, then hands back the take with chapters and suggested cuts to edit like any recording. It records public web pages, and signed-in pages with a login you've saved in Tella, but not desktop or mobile apps. 【28†How Auto Capture works】.
L108: 
L109: Which AI tools can connect to Tella?
L110: ChatGPT and Claude, through the Tella app in each one's app directory, plus any MCP client that supports remote HTTP servers. Setup instructions are available for Claude Code, Codex, Cursor and OpenCode.
L111: 
L112: How do I connect Claude Code, Codex or OpenCode to Tella?
L113: Run one command, then sign in to Tella in your browser when prompted. In Claude Code: claude mcp add --transport http --scope user tella https://api.tella.com/mcp. In Codex: codex mcp add tella --url https://api.tella.com/mcp. In OpenCode: opencode mcp add tella --url https://api.tella.com/mcp, then opencode mcp auth tella to sign in.
L114: 
L115: What is a video editing MCP server?
L116: An MCP server gives an AI agent tools it can call. A video editing MCP server gives it editing tools: cut a clip, remove filler words, add a zoom, change a layout, export. Tella's MCP server works on the videos in your Tella workspace, so Claude, ChatGPT, Codex or Cursor can edit a real recording instead of generating a new one.
L117: 
L118: What can an agent edit?
L119: Agents can cut by transcript, remove filler words and silences, apply layouts and B-roll, add zooms, blurs, text and captions, set chapters, clean up audio with Studio Sound, resize for social, and export. The 【27†Edit video with AI agents】 guides walk through each job.
L120: 
L121: Can an agent publish a video for me?
L122: Yes. Agents can export finished videos, generate share links, organize them into playlists, and publish to your connected YouTube, LinkedIn, X, Instagram and Facebook accounts. You decide what access each connected agent receives.
L123: 
L124: Is the Tella MCP free?
L125: 
L126: The MCP server is included on every Tella plan, including the free trial, with no add-on. Auto Capture is included with paid plans and uses credits for each take.
L127: 
L128: Do I need to write code?
L129: No. Most MCP clients connect with one command or a short configuration snippet. Once connected, you can ask your agent to work in natural language.
