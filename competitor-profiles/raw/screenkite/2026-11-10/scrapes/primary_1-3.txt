L37: ## Set Up
L38: ### 1. Install the command line tool
L39: 
L40: Choose ScreenKite → Install Command Line Tool.... This installs the `screenkite` command. You can see its status in Settings → Editor → AI Agent Editing.
L41: 【46†Image: ScreenKite app menu with the Install Command Line Tool item highlighted】The ScreenKite menu with Install Command Line Tool selected【47†Image: ScreenKite Settings Editor page with the AI Agent Editing section showing CLI Status Installed】Settings, Editor, AI Agent Editing: the CLI status, the CLI path and the agent entry points
L42: ### 2. Set up transcription
L43: 
L44: Cuts by transcript need word timings. Set up a transcription engine in Settings → Transcription before you ask for transcript cuts. See 【48†Word-Level Generated Captions】.
L45: ### 3. Connect your agent
L46: 
L47: In the editor, click CLI / MCP in the top toolbar. The Connect an agent window opens. It shows how to connect your agent. Click Copy prompt and paste the prompt into your agent. Each open editor window runs its own local server on your Mac.
L48: 
L49: 【49†Image: ScreenKite Connect an agent window with the CLI tab and the Connect any agent to ScreenKite MCP prompt】The Connect an agent window: the Agent CLI card, the MCP prompt to copy, and Commands & advanced

L51: ✅
L52: Claude Desktop: The prompt in Connect an agent gives the command and arguments for a stdio MCP server. Add them to the MCP config file of Claude Desktop. Claude Desktop also includes Claude Code. ScreenKite finds it, so the 【44†AI Chat Assistant】 can use it.
L53: ## Ask Your Agent
L54: 
L55: You write a sentence. The agent calls ScreenKite tools for you. For example:
L56: 
L57:     Open ~/Desktop/Recording.skbundle and transcribe the microphone track.
L58:     Propose cuts for false starts and filler words. Show me the list before you apply it.
L59: 
L60: 
L61:     Add B-roll to the three main points of the talk. Use a corner layout.
L62: ## What the Agent Calls
L63: 
L64: The CLI and the agent use the same commands. You can run them yourself:
L65: 
L66:     # Open a project
L67:     screenkite project open --path ~/Desktop/Recording.skbundle --json
L68: 
L69:     # List the tools and read one tool's options
L70:     screenkite tool list
L71:     screenkite tool describe --name edit-timeline
L72: 
L73:     # Read the project state
L74:     screenkite tool call --name stat --input-json '{"scope":"summary"}' --json
L75: 
L76: 
L77: Add `--json` to get output that a program can read.
L78: ## Propose, Then Apply
L79: 
L80: Some actions take a `confirm` field:
L81: 
L82: Tool  | Action
L83: --- | ---
L84: `edit-timeline`  | `cut`
L85: `edit-words`  | `cutSilences`, `removeWords`, `removeDeadAir`
L86: `markers`  | `generateChapters`
L87: `fx`  | `captions/import`, `captions/patch`, `voiceover/replace`, `camera/replace`
L88: 
L89: With `confirm:false`, the action returns its plan and changes nothing. A second call with `confirm:true` applies the plan.
L90: Other actions do not take `confirm`. For example, `rm-track`, `rm-asset`, `edit-timeline` `delete` and `fx` `broll_slot/accept` apply at once.
L91: 
L92: ⚠️
L93: 
L94: ScreenKite does not wait for you between the two calls. An agent in a terminal can send both calls itself. If you want to see the plan first, tell the agent to stop and show it to you. The AI Agent panel in the editor can ask you before it applies an edit. See 【44†AI Chat Assistant】.
L95: ## Transcript Cuts
L96: 
L97: The agent can:
L98: 
L99:   1. Check that transcription is ready.
L100:   2. Transcribe the microphone track with word timings.
L101:   3. Propose cuts for false starts, filler words and silences.
L102:   4. Apply the cuts with `confirm:true`.
L103: 
L104: The same word timings make captions. See 【48†Word-Level Generated Captions】.
