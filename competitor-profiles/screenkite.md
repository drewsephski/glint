# ScreenKite
Checked: 2026-11-10. Scope: official product, pricing and agent documentation; existing repository static analysis is supplementary.

## Observed
The [agent guide](https://www.screenkite.com/en/guide/agentic-video-editing) documents CLI/MCP editing, shared editor tools, undo, and plan/apply operations. Some actions apply directly; terminal agents can issue both plan and apply calls. [Pricing](https://www.screenkite.com/en/pricing) lists free watermarked exports, with Pro removing the watermark and adding S3 upload/support. The [homepage](https://www.screenkite.com/en) says $99.99 once for three Macs; pricing retains $79.99 founder copy explicitly ending October 31, 2026.

## Interpretation
The closest established local agent-editor competitor. BYO coding agents, MCP and one shared editing engine already overlap with Glint. Use $99.99 as the advertised post-promotion price, with checkout unverified.

## Implication for Glint
Compete on successful repeat runs, grounded narration and controlled scene replacement. Do not describe ScreenKite as lacking agent tools or previewable plans.

## Uncertainty
Feature breadth and speed were not benchmarked. Vendor comparison tables are not evidence about other products.
