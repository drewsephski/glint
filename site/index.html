Glint is a native macOS screen recorder and editor. It reads what you did on screen and adds zooms, a smooth cursor, tighter pacing and captions. Your AI agents can do every one of those steps too. Their edits are labelled with who made them and can be undone, and bigger changes arrive as proposals you can preview before applying.

Download Glint 0.4.0 View the source on GitHub

For Apple Silicon Macs on macOS 26 or later. Signed with Developer ID and notarized by Apple. 5.4 MB disk image.

What Glint adds to a raw take

While you record, Glint logs the pointer, clicks and typing next to the video. The editor uses that log to build each lane of the timeline. Nothing touches your original media.

  1. Video

    Tighten

    Silent pauses get shorter, filler words are cut, and silent typing and idle waiting speed up.

  2. Zoom

    Auto zoom

    Clicks and typing become zooms that start before each action and hold after it. Nearby zooms merge or pan instead of pumping in and out.

  3. Cursor

    Smooth cursor

    A redrawn cursor that moves smoothly and still lands exactly on each click, with click ripples and an idle fade.

  4. Captions

    Captions

    Transcribed on your Mac with Apple's speech recognition, split into readable lines with the spoken word highlighted.

  5. Voice

    Narration Optional

    Glint splits the take into scenes, Claude writes a line for each, and an ElevenLabs voice reads them. The picture is retimed to fit each line. Uses your own API keys.

Everything in the current release

These are in Glint 0.4.0, the latest download. Newer features that haven't shipped yet are listed under Available in source builds.

Record a display or a window
Captured with ScreenCaptureKit in HEVC at up to 60 fps, with system audio and an optional microphone. Start from the app with ⇧⌘R.
Facecam New in 0.4.0
Your camera records to its own track and appears as a bubble: circle, square or wide, in any corner. It follows your cuts, shrinks while the screen zooms, and captions move out of its way.
Private input tracking
Glint records when you type, never which keys. Input tracking needs no extra permission.
Backgrounds and canvases
Gradient or image backgrounds, padding, rounded corners and shadow. Export 16:9, 1:1, 9:16 or 4:3; square and vertical versions follow the cursor.
Export that checks itself
H.264, HEVC, ProRes and GIF, with loudness normalized toward −16 LUFS. Every output is measured for length, resolution, black or frozen frames, sharpness, loudness and clipping.
Non-destructive projects
Your media is never modified. A project is an open folder of JSON and standard media files. Deleted recordings go to the Trash, so Finder can put them back.
Undo everything, from anyone
Every edit is a transaction with an author. Undo, redo, or revert one earlier change on its own, whether you or an agent made it.
Quality checks before you render
Glint flags zooms that pump, a cursor that leaves the frame while zoomed, fast camera moves, dead air and captions that go by too quickly, each with a suggested fix.

You and your agent edit the same project

The app, the glint command line tool and Glint's MCP server all run on one engine. An agent's edit shows up live in the editor you have open, and you can undo it like any other.

Working in the app

  1. Record, or open the demo project to try Glint without any permissions.
  2. Click Auto Zoom, Tighten and Captions, or ask in the editor's Chat tab: "tighten the pauses and add zooms".
  3. Preview proposals from planners and agents, then apply or reject them.
  4. When an agent asks Glint to record or send something online, approve or deny it from the banner at the top. If your Glint policy already allows that kind of action, it goes ahead without asking.
  5. Export the formats you need.

Working through an agent

  1. Connect Claude Code, Codex or Claude Desktop with one click in Glint, or run glint connect.
  2. The agent reads the take: events, transcript, frames and contact sheets.
  3. It applies reversible edits directly, each labelled with the agent's name and undoable, or proposes cuts, zooms and captions with a reason. It can render and score a proposal before anyone applies it.
  4. It renders each variant and reads the measurements back.
  5. Glint's recording, delete and online tools return an approval request unless your Glint policy allows them, and agents can't approve their own requests. This covers Glint's tools only; the agent's other tools follow its own permission settings.

Connect from the terminal

/Applications/Glint.app/Contents/Helpers/glint connect
/Applications/Glint.app/Contents/Helpers/glint connect --status

Glint checks that its server answers before changing any config, edits only its own entry and keeps a backup. Cursor, VS Code, Windsurf and Zed get a snippet to paste: add --print to the same command. To type plain glint instead of the full path, run /Applications/Glint.app/Contents/Helpers/glint install-cli once; it links the tool into ~/.local/bin, which needs to be on your PATH.

  • Chat in the editor. The Chat tab runs Claude Code or Codex with your existing sign-in, so Glint needs no API key for it. You see its tool calls as they happen. As with any use of those agents, your messages and what the agent reads from the project go to its provider.
  • Recordings stay visible. When an agent records, it happens in Glint.app. You see it and can stop it there, and macOS asks for Screen Recording once, for Glint.
  • Agent walkthroughs. An agent driving an app can report its clicks and typing, so automation that never moves the real pointer still gets zooms and a natural cursor.
  • One set of tools for MCP and the CLI. Recording, editing, narration, rendering and measurement. Source builds have more tools than the 0.4.0 release; docs/AGENTS.md lists the current set.

Runs on your Mac. Online only when you choose.

Recording, zooms, cuts, captions and export all run locally. Two optional features send data off your Mac: narration, through your own Anthropic and ElevenLabs accounts, and working with an AI agent, through the agent's own provider.

Stays on your Mac

  • Screen, camera and audio recording
  • Pointer and click tracking, and keystroke timing (never the keys)
  • Transcription and captions
  • Scene detection and on-screen text reading for narration
  • Editing, rendering and quality checks

Leaves your Mac only when you use these

  • Narration script, to Anthropic: a frame from each scene, its on-screen text, the actions you took, any recorded speech and your brief, so Claude can write the lines. Uses your Anthropic key.
  • Narration voice, to ElevenLabs: only the script, so a voice can read it. Uses your ElevenLabs key.
  • Agent chat and connected agents, to that agent's provider: when you use the Chat tab or connect Claude Code, Codex or another agent, your messages, the project context it reads, the results of the Glint tools it calls and any frames it asks for go to the provider behind that agent, under your account with them.

You add narration keys in Glint › Settings › Narration. They are stored in your macOS Keychain, are not part of the app, and agents can't read or set them. When an agent asks Glint to call Anthropic or ElevenLabs, Glint asks you first unless your Glint policy already allows online calls. Glint can't limit what an agent sends through its own tools or to its own provider; that is set in the agent's settings.

Get started

  1. Download and install

    Download Glint-0.4.0.dmg, open it and drag Glint to Applications. A ZIP and SHA-256 checksums are on the release page.

  2. Open Glint

    A short setup runs the first time. macOS asks for Screen Recording permission when you first record, and for camera or microphone access only if you turn them on.

  3. Make your first demo

    Press ⇧⌘R to record, or click Demo project to explore a sample. Then try Auto Zoom, Tighten and Captions.

  4. Connect your agents

    Home › Agents has a Connect button for Claude Code, Codex and Claude Desktop.

Available in source builds

These features are on Glint's main branch and are coming in the next release. The Glint 0.4.0 download doesn't include them. To use them now, build Glint from source with the steps below. The screenshots on this page come from release builds and don't show these features.

Editing

  • Several shots in one project: import movies, then append, insert, split, reorder, trim or remove them. Edits stay on their content when shots move, and shots of another shape are letterboxed.
  • A music bed that loops, fades and lowers itself under narration, your own recorded voiceover, and sound effects.
  • Dip-to-black or dip-to-white transitions, including fade in and fade out.
  • Callouts: text labels, arrows, boxes and spotlight highlights that zoom with the screen, drawn and adjusted right on the preview.
  • Privacy masks (pixelate, blur or solid) for a time range, placed by you or an agent and drawn into the preview, stills, GIFs and every export.
  • Captions export to SRT and WebVTT timed to the edited video, and can be imported. Choose font, weight, size, colours and position.
  • Cut words straight from the transcript, or every occurrence of a phrase.
  • Reusable style presets, timeline trim handles, snapping, and a keyboard shortcut sheet (⌘/).

Recording

  • Pause and resume a take. Screen, audio, camera and input stay in sync with no gap.
  • Crash recovery: takes are written in 2-second fragments, so an interrupted take can be rebuilt from Home or with glint recover. Up to about the last 2 seconds can be lost.
  • A preflight check before each take covers permission, source, microphone and camera, folder and disk space, with a fix for each problem.
  • Window recordings follow a window that is moved during the take.

Agents

  • Demo recipes: versioned scenes with stable IDs, steps and expected outcomes. Your agent drives the app; Glint records and checks.
  • Evidence for each outcome: verified, failed or needs review. A click never counts as proof. Glint checks on-screen text itself with on-device OCR; other outcomes need a check from the agent or a person.
  • Scene refresh: after a product change, re-record one scene and swap it in. Your manual edits outside that scene are kept.
  • Render and production jobs with progress, cancel and retry. A job runs inside the app, CLI or MCP server that started it and saves a checkpoint after each stage. If that process quits or crashes, retrying the job continues after the last completed stage.
  • A production job only succeeds when every check passes. Otherwise it lists what needs review.

Build from source

Needs an Apple Silicon Mac with macOS 26 and Xcode 26 (Swift 6.2 or later).

git clone https://github.com/drewsephski/glint.git
cd glint
scripts/build-app.sh
open build/Glint.app
build/Glint.app/Contents/Helpers/glint install-cli
build/Glint.app/Contents/Helpers/glint connect

install-cli links glint into ~/.local/bin (add it to your PATH if it isn't already), and connect points Claude Code, Codex and Claude Desktop at this build. A source build is signed ad hoc rather than notarized, so macOS may ask for Screen Recording permission again after a rebuild. See the README for the full quick start and the new commands.

Questions

Do I need an API key?

Not for recording, editing, captions or export. Narration needs your own Anthropic key to write the script and an ElevenLabs key for the voice. You can also write the narration lines yourself. The editor's Chat tab uses your existing Claude Code or Codex sign-in instead of a key, and what you send there goes to that agent's provider.

Can an agent record my screen without me knowing?

When an agent uses Glint's tools to start a recording, delete or overwrite files, or send something online, Glint returns an approval request, unless your Glint policy already allows that kind of action. You approve it in the Glint app, or with glint approve in an interactive terminal; agents can't approve their own requests. Agent recordings normally run in Glint.app, where you can see and stop them. Reversible edits don't need approval: they're labelled with the agent's name and you can undo them. Approvals only cover Glint's tools, not anything an agent does with its own tools. They stop well-behaved agents from acting alone and are not a security boundary against other software running as your user.

Which agents work with Glint?

Claude Code, Codex (CLI, IDE extension and app) and Claude Desktop connect with one click. Cursor, VS Code, Windsurf and Zed work through a config snippet Glint gives you. Any MCP client that runs a stdio server can use it.

Does it work on Intel Macs or older macOS versions?

No. Glint needs an Apple Silicon Mac running macOS 26 or later. It relies on the speech recognition and SwiftUI features in macOS 26.

Is every feature on GitHub in the download?

No. The download is the latest tagged release, currently 0.4.0. The main branch already has newer features, such as several shots per project, music, callouts, privacy masks, SRT and WebVTT captions, pause and resume, crash recovery, recipes and jobs. They're listed under Available in source builds and are only in apps you build from source until the next release. The release notes say what each version includes.

What isn't there yet?

The 0.4.0 download doesn't have callouts, masks, transitions, several shots per project, music, SRT or WebVTT export, pause and resume, or crash recovery; those are in source builds. Neither the release nor source builds have automatic updates, crossfades, picture-in-picture, device frames, transcription of imported clips, or automatic detection of sensitive content (masks are placed by a person or agent). Glint doesn't explore or drive apps by itself. For the facecam, dragging the bubble and full-screen or side-by-side layouts aren't done yet. The full list for the current source is in docs/GAPS.md.

Do render jobs keep running if Glint quits?

Jobs are only in source builds. A job runs inside the app, CLI or MCP server that started it; there's no separate background service. If that process quits or crashes, the job shows as interrupted. It saves a checkpoint after each stage, so retrying it continues after the last completed stage instead of starting over.

Where are my projects stored?

New recordings go to ~/Movies/Glint. Each project is a folder of JSON files and standard media you can open in other tools.
